# Установка

Отдельное Android-дополнение: [Голос для Dune](dune-voice/README.md) —
кнопка микрофона на приставке и «Эй, Дюна» на телефоне, без NAS.
Это два APK; они устанавливаются отдельно от PHP- и JS-плагинов ниже.

Для сохранения прогресса добавьте в **Lampa → Настройки → Расширения / Плагины** ссылку:

```text
https://raw.githubusercontent.com/vladikshkwok/lampa-dune-plugins/main/plugins/dune-local-progress.js
```

Для передачи обложки и описания добавьте второй плагин:

```text
https://raw.githubusercontent.com/vladikshkwok/lampa-dune-plugins/main/plugins/dune-native-player.js
```

JS-файлы скачивать вручную не нужно. Для обложки и описания дополнительно установите нативный мост из [Releases](https://github.com/vladikshkwok/lampa-dune-plugins/releases):

1. Откройте `dune_plugin_lampa_dune_bridge.zip` в файловом браузере **Dune HD**, чтобы установить нативный плагин.
2. Добавьте нужные JS-плагины по ссылкам выше. При желании их можно разместить на своём сервере.
3. В нативном Android-меню Lampa включите **«Удержание сокета»** и перезапустите приложение.
4. Запускайте видео через внешний **Dune HD Player**. Информацию открывайте кнопкой **INFO**.

Для одного сохранения прогресса достаточно `dune-local-progress.js`; нативный ZIP и второй JS нужны для передачи карточки фильма.

## О плагинах

Плагины для Android-приложения Lampa и встроенного плеера Dune HD:

- **Прогресс просмотра** — сохраняет позицию в локальной истории Lampa и позволяет продолжить просмотр; с включённым в Lampa «TrackTimecode» отдаёт её и в TorrServer, так что просмотр на Dune продолжается на телефоне или ПК, и наоборот. Номера серий понимает и в именах, которые Lampa не разбирает (`Show.S01E.01`, `S01.E01`, `1x01`, «Серия 4»); иначе Lampa давала всем сериям сезона общий прогресс.
- **Обложка и описание** — передаёт карточку фильма и плейлист нативному плееру.
- **Состояние потока** — использует штатную статистику TorrServer в информационном экране Dune, без постоянной надписи поверх видео.

Прогресс считывается через API самой приставки. Дополнительный сервер или замена APK не нужны. Обложки загружаются по ссылкам из Lampa; статистику предоставляет ваш TorrServer.

## TorrServer через прокси

Dune распознаёт поток по адресу вида `http://SERVER:8095/stream/FILE?link=…&index=…&play`. Префикс прокси (`/PREFIX/stream/…`) мешает штатной статистике.

В этом случае откройте **Lampa → Настройки → Dune HD → Прямой адрес TorrServer** и укажите адрес **своего** сервера без префикса, доступный с приставки. Для прямого адреса поле обычно оставляют пустым.

Настройка привязывается к текущему TorrServer Lampa. При смене сервера настройте её заново. Перед обходом прокси плагин проверяет наличие выбранного торрента read-only запросом; при недоступности сервера сохраняет исходную ссылку. В распространяемых файлах нет настроек домашней сети или ключей.

## Совместимость

Проверено на Dune HD Pro Vision 4K (`tv184a`), Android 11, прошивке `250815_1012_r22`, Lampa 1.13.1/code568. Подтверждены сохранение после перемотки и перезапуска, продолжение с сохранённой позиции, передача обложки, описания и плейлиста. Отображение штатной строки статистики на телевизоре пока требует подтверждения.

Требуются IP Control API Dune с JSON (протокол5+) и PHP-плагины для нативной карточки. Используются локальные порты80/11080; другие модели пока не проверены. Режим удержания сокета обязателен для фонового считывания позиции.

Прогресс сохраняется локально примерно раз в секунду, без отправки в облако. Если в **Lampa → Настройки → TorrServer** включён «TrackTimecode», позиция торрент-файла пишется и в TorrServer тем же запросом, что делает сама Lampa при закрытии своего плеера (`POST <TorrServer>/viewed`, `{action:"set", hash, file_index, timecode}` в целых секундах): после 30 с просмотра, затем раз в 30 с, сразу после перемотки и при остановке. Запись идёт на TorrServer, указанный в Lampa (с её авторизацией); `http`-адрес на `https`-странице пропускается. Сбой записи не влияет на просмотр и локальную историю. Другие клиенты Lampa подхватывают позицию при открытии списка файлов торрента — так Lampa читает TorrServer и сама; Dune так же получает позицию, сохранённую в другом месте. В самом TorrServer тоже должен быть включён «TrackTimecode» (`/settings`), иначе он хранит 0. Остановка не означает «просмотрено полностью»: отправляется последняя реальная позиция. При завершении процесса останется последняя сохранённая позиция. Потоки с отдельными HTTP-заголовками запускаются обычным способом. При переходе на другой внешний плеер отключите передачу карточки в настройках **Dune HD**.

Удаление: отключите JS-плагины и перезапустите Lampa; нативный плагин удаляется через управление плагинами Dune.

## Сборка и проверки

Нужны Python3, Node.js с `node:test` и PHP для PHP-проверки.

```sh
node --test tests/dune-local-progress.test.js tests/dune-native-player.test.js
php tests/dune-native-bridge.test.php
python dune-native-bridge/build.py
```

Архивы создаются в `dist/`, сборочные файлы не хранятся в Git. В репозитории только исходники плагинов, тесты и сборщик; APK, Dune SDK, логи и пользовательские конфиги не включены.

[Свой Jackett для «Онлайн фильмов и сериалов»](https://github.com/vladikshkwok/dune-online-movies-jackett) настраивается отдельно.
