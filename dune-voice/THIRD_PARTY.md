# Third-party components

The standalone `dune-voice/` application and shared source in this directory
are licensed under Apache-2.0 (see LICENSE). The existing Lampa/PHP plugins
outside this directory retain their own GPL-2.0 license.

The TV APK bundles no third-party code: speech recognition is the voice
service already installed in the device firmware.
No cloud account, subscription or API key is bundled or required.
