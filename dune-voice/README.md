# Голос для Dune

Два самостоятельных Android-приложения без NAS, веб-пульта и аккаунта разработчика:

- **dune-voice-tv.apk** устанавливается на Dune. Кнопка микрофона пульта
  открывает голосовую команду. Распознаёт установленный в прошивке голосовой
  сервис; ему может требоваться интернет.
- **dune-voice-phone.apk** устанавливается на Android-телефон. После включения
  слушает «Эй, Дюна» с погашенным экраном. Русская модель Vosk включена в APK;
  распознавание происходит на телефоне без облака. Команда передаётся напрямую
  приложению на приставке по домашней сети.

Это APK-дополнение для Android-моделей Dune. Штатные PHP-плагины в ZIP
используют другой механизм и не заменяют этот модуль. Root и ADB для
пользования не нужны. APK можно передать другим владельцам совместимых Dune:
личных адресов, токенов, URL навыка Алисы и настроек разработчика внутри нет.

## Установка на Dune

1. Скопируйте `dune-voice-tv.apk` на приставку и откройте файл для установки.
2. Откройте **Голос для Dune → Включить кнопку микрофона**.
   В специальных возможностях включите **Кнопка микрофона Dune**. Если
   прошивка не открывает этот раздел сама, приложение откроет экран
   специальных возможностей Dune или общие настройки и подскажет путь.
   Слева на главном экране видно, что уже настроено: кнопка микрофона,
   телефон, Lampa и фоновая работа.
   Содержимое экрана служба не считывает; ей нужен только перехват кнопок.
3. В приложении нажмите **Сказать команду**, разрешите микрофон и проверьте
   «Найди фильм Зелёная миля».
4. Нажмите микрофон на пульте. Если прошивка продолжает вызывать другого
   помощника, используйте кнопку **Выбрать голосового помощника** и выберите
   **Голос для Dune** в системном диалоге.

По умолчанию поиск идёт **в Lampa** (`top.rootu.lampa`). Название можно
произнести без уточнения приложения. Явное «в Лампе» тоже поддерживается.
Выбор фильма, качества и источника остаётся ручным. Встроенный каталог Dune
пока не подключён: явная просьба искать там возвращает пояснение вместо
поиска в другом приложении.

## Подключение телефона

1. На Dune откройте **Подключить телефон**: крупный код появится вверху экрана. Разрешите приложению
   фоновую работу, чтобы связь не блокировалась в режиме ожидания, затем
   откройте подключение ещё раз.
2. Установите `dune-voice-phone.apk` на телефон. При первом открытии приложение
   автоматически ищет Dune в сети. Выберите свою приставку в списке,
   введите восьмизначный код с её экрана и нажмите **Подключить телефон**.
   Код действует три минуты, допускает пять неверных попыток и используется
   один раз. Новое подключение заменяет предыдущее.
3. Нажмите большую кнопку микрофона и разрешите микрофон и уведомления.
   При первой активации распаковывается русская модель. После подключения
   на экране телефона появляется и обычный пульт: поиск по названию с
   клавиатуры, пауза, громкость, «Назад», «Домой» и запуск Lampa.
4. Для работы в глубоком сне телефона нажмите **Разрешить работу при
   погашенном экране** и подтвердите системный запрос.

Для автопоиска обновите APK **на обоих устройствах**. Кнопка **Найти Dune
в сети** повторяет поиск. Если приставка не найдена, её IPv4-адрес по-прежнему
можно ввести вручную. Обнаружение использует mDNS/DNS-SD и работает в одном
локальном сегменте; гостевой Wi-Fi, изоляция клиентов и разные подсети
роутеров могут блокировать его. Поиск не передаёт код или ключ доступа и
не выполняет команды. Подключение по коду остаётся обязательным.

## Кнопка в шторке телефона

После подключения и выдачи разрешения на микрофон нажмите в приложении
**Добавить кнопку в шторку**. На Android 13 и новее подтвердите системное
добавление плитки **Эй, Дюна**. Либо дважды раскройте шторку, нажмите карандаш
или **Изменить** и перетащите **Эй, Дюна** в быстрые настройки.

Нажатие включает прослушивание, повторное — выключает. Активная плитка
подсвечена и показывает **Микрофон включён**. При включении Android может
попросить разблокировать телефон; кратко появляется окно запуска микрофона.
Если телефон ещё не подключён или нет разрешения на микрофон, открывается
настройка приложения. Выключение освобождает микрофон и блокировку сна.

## Использование голосовой активации

Теперь приложение можно закрыть и погасить экран. Скажите «Эй, Дюна»;
после короткой вибрации произнесите команду. Можно сказать всё одной
фразой: **«Эй, Дюна, найди фильм Зелёная миля»**.

Фразу активации всегда распознаёт встроенная модель на телефоне. Маленькая
модель редко пишет её дословно («эйдена», «эй диона», «все диона»), поэтому
принимаются эти варианты в начале фразы; обычные имена вроде «Дина» или
«Дуня» её не включают. Если после «Эй, Дюна» была пауза, команду слушает
системный распознаватель (обычно Google) — он точнее с названиями фильмов.
Если его нет или он не сработал, команду в течение восьми секунд разбирает
встроенная модель. Это переключается в **Настройках** приложения.

Уведомление показывает, что расслышано и что ответила Dune, например
«найди фильм зелёная миля» → Ищу: зелёная миля. Пока приложение открыто,
под кнопкой микрофона видно, что телефон слышит прямо сейчас.
Пока включён режим, микрофон используется постоянно и расходуется батарея.
Уведомление содержит кнопку **Выключить**. Работает и голосовая команда
«Эй, Дюна, выключи микрофон».

После перезагрузки, принудительной остановки или отзыва разрешения включите
прослушивание снова. Это пользовательский режим с foreground service,
а не системный энергосберегающий детектор Google. Работа на конкретном
телефоне зависит от его политики батареи и разрешений.

Телефон и Dune должны быть доступны друг другу по домашней сети.
Аудиозаписи и история распознанных фраз не сохраняются: в приватных данных
приложения остаётся только текст последнего статуса для уведомления. На Dune передаётся
только текст после фразы активации. **Отключить телефон** на приставке
немедленно отменяет его ключ доступа.

## Команды

- «Найди фильм …», «Покажи сериал …», «Хочу посмотреть …», просто название.
- «Открой Lampa».
- «Пауза», «Поставь на паузу», «Продолжи», «Стоп».
- «Громче», «Сделай тише», «Выключи звук», «Включи звук».
- «Домой», «Назад», «Включи Дюну», «Выключи приставку».

Разбор локальный и ограничен этими действиями. Это не универсальная LLM:
приложение не выбирает фильм по описанию и не выполняет произвольные команды.
Названия передаются как данные, без shell-команд и подстановок.

## Совместимость и ограничения

Минимальная версия Android — 8.0. Телефонный APK содержит библиотеки arm64-v8a
и x86_64; 32-битные телефоны не поддерживаются. ARM64-библиотеки Vosk и JNA
имеют выравнивание ELF 16 КБ; APK собирается с `zipalign -P 16`.

Для Dune нужны Bluetooth-пульт с микрофоном, Android-сервис распознавания,
Lampa для поиска и локальный Dune IP Control с JSON на порту 80 или 11080.
На Android-моделях без этого API часть управления плеером недоступна.
Управление сторонними Android-плеерами зависит от их MediaSession.
Распознавание реального звука с R4 и работа на Pixel 9a требуют проверки
владельцем; установка и программные проверки выполнены на Pro Vision 4K
tv184a/Android 11 и Android 14 в эмуляторе соответственно.

Связь телефона использует только локальные IPv4-адреса и порт 18766.
Приставка объявляет `_dune-voice._tcp.` после запуска API. Неавторизованный
`POST /discover` возвращает только название устройства и версию протокола;
телефон проверяет их до добавления адреса в список. Поиск ограничен 12 секундами
и прекращается при закрытии экрана подключения.
Подключение выдаёт случайный 256-битный ключ, хранящийся в приватных данных
приложений. API отклоняет браузерный Origin, неизвестные маршруты,
неавторизованные и слишком большие запросы. Повтор одного ID команды
возвращает сохранённый результат. Передача в домашней сети использует HTTP;
не публикуйте порт 18766 в интернет.

## Сборка и проверки

На Windows Git Bash нужны JDK 17+, Android SDK platform 36/build-tools 36.0.0
и Python 3. Подпись создаётся в `~/.android/dune-voice.jks`, пароль — рядом
в `.pass`. Сохраните ключ для обновлений; в Git они не попадают.

```sh
sh dune-voice/build.sh test
sh dune-voice/build.sh tv
sh dune-voice/build.sh phone
```

Входные AAR и русская модель закреплены SHA-256 в `dependencies.json`.
При первой сборке скачиваются с Maven Central и сайта Vosk. Результат в
`dune-voice/build/tv/` и `dune-voice/build/phone/`; зависимости — в `.cache/`.
Эти каталоги игнорируются Git.

Дополнительные проверки для лаборатории:

- `build.sh phone probe` добавляет `NativeProbe`: на эмуляторе проверить
  `adb shell am instrument -w org.duckdns.dunevoice.phone/.NativeProbe`.
- `build.sh tv probe` добавляет `GatewayProbe` для одноразового подключения,
  авторизации и отключения без команд устройству. Не запускайте на уже
  подключённой пользовательской приставке.
- `tests/gateway_probe.py` проверяет отклонение запросов без ключа через
  предварительный SSH/ADB-forward `localhost:18766 → Dune:18766`.
- `tests/emulator_background.py --adb PATH` проверяет запись с выключенным
  экраном и освобождение микрофона/wake lock. Принимает только emulator serial.
- `tests/instrument_probe.py phone --discovery --adb PATH --serial emulator-5580`
  проверяет реальное mDNS-обнаружение и HTTP-проверку идентичности сервиса
  в probe-сборке на эмуляторе.
- `tests/emulator_tile.py --adb PATH` проверяет включение и выключение
  микрофона через системную плитку, реальную запись и освобождение ресурсов.
  Нужен одноразовый rooted-эмулятор; физические устройства отклоняются.
- `tests/package_check.py` проверяет обычные APK перед распространением.

В распространяемые APK instrumentation не включается. После лабораторных
проверок обязательно пересоберите обычные `tv` и `phone`.
