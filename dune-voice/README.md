# Голос для Dune

Самостоятельное Android-приложение для Dune без NAS, веб-пульта и аккаунта
разработчика: **dune-voice-tv.apk** ставится на приставку, и кнопка микрофона
пульта открывает голосовую команду. Распознаёт установленный в прошивке
голосовой сервис; ему может требоваться интернет.

Это APK-дополнение для Android-моделей Dune. Штатные PHP-плагины в ZIP
используют другой механизм и не заменяют этот модуль. Root и ADB для
пользования не нужны. APK можно передать другим владельцам совместимых Dune:
личных адресов, токенов и настроек разработчика внутри нет.

Раньше рядом было приложение для телефона («Эй, Дюна» с погашенным экраном).
Оно удалено 2026-10-16: голос без рук закрывает Алиса, а приложению на Dune
больше не нужен сетевой шлюз для телефона — порт 18766 и сопряжение по коду
исчезли вместе с ним.

## Установка на Dune

1. Скопируйте `dune-voice-tv.apk` на приставку и откройте файл для установки.
2. Откройте **Голос для Dune → Включить кнопку микрофона**.
   В специальных возможностях включите **Кнопка микрофона Dune**. Если
   прошивка не открывает этот раздел сама, приложение откроет экран
   специальных возможностей Dune или общие настройки и подскажет путь.
   Слева на главном экране видно, включена ли кнопка и установлена ли Lampa.
   Содержимое экрана служба не считывает; ей нужен только перехват кнопок.
3. В приложении нажмите **Сказать команду**, разрешите микрофон и проверьте
   «Найди фильм Зелёная миля».
4. Нажмите микрофон на пульте. Если прошивка продолжает вызывать другого
   помощника, используйте кнопку **Сделать помощником по умолчанию** и выберите
   **Голос для Dune** в системном диалоге.

По умолчанию поиск идёт **в Lampa** (`top.rootu.lampa`). Название можно
произнести без уточнения приложения. Явное «в Лампе» тоже поддерживается.
Выбор фильма, качества и источника остаётся ручным. Встроенный каталог Dune
пока не подключён: явная просьба искать там возвращает пояснение вместо
поиска в другом приложении.

## Команды

- «Найди фильм …», «Покажи сериал …», «Хочу посмотреть …», просто название.
- «Найди в ютубе …», «Покажи на YouTube …», «Найди видео про … в ютубе», «Открой ютуб».
  Поиск открывается в SmartTube, а если его нет — в официальном YouTube для ТВ
  (обоим передаётся ссылка `youtube.com/results?search_query=…`).
- «Открой Lampa».
- «Пауза», «Поставь на паузу», «Продолжи», «Стоп».
- «Громче», «Сделай тише», «Выключи звук», «Включи звук».
- «Домой», «Назад», «Включи Дюну», «Выключи приставку».

Разбор локальный и ограничен этими действиями. Это не универсальная LLM:
приложение не выбирает фильм по описанию и не выполняет произвольные команды.
Названия передаются как данные, без shell-команд и подстановок.

## Совместимость и ограничения

Минимальная версия Android — 8.0. Нужны Bluetooth-пульт с микрофоном,
Android-сервис распознавания, Lampa для поиска и локальный Dune IP Control
с JSON на порту 80 или 11080. На Android-моделях без этого API часть
управления плеером недоступна. Управление сторонними Android-плеерами
зависит от их MediaSession. Установка и программные проверки выполнены на
Pro Vision 4K tv184a/Android 11; распознавание живой речи с R4 проверяет владелец.

## Сборка и проверки

На Windows Git Bash нужны JDK 17+, Android SDK platform 36/build-tools 36.0.0
и Python 3. Подпись создаётся в `~/.android/dune-voice.jks`, пароль — рядом
в `.pass`. Сохраните ключ для обновлений; в Git они не попадают.

```sh
sh dune-voice/build.sh test
sh dune-voice/build.sh tv
python dune-voice/tests/package_check.py
```

Сторонних библиотек нет, при сборке ничего не скачивается. Результат —
`dune-voice/build/tv/dune-voice-tv.apk`; каталог игнорируется Git.
`tests/package_check.py` проверяет APK перед распространением: лицензии на
месте, личных адресов и доменов внутри нет.
